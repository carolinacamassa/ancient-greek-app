# Data format

`pipeline/build.py` writes three kinds of file into `app/public/data/`. Keys are short because the files are loaded on phones.

## manifest.json

```json
{
  "generated": "2026-10-10",
  "corpusLemmas": 6100, "corpusTokens": 83900,
  "texts": [{
    "id": "aesop", "title": "Fables 1–53", "author": "Aesop", "stage": 1, "optional": false,
    "analysis": "manual", "dialect": "Koine (simple narrative)", "description": "…",
    "file": "texts/aesop.json", "bytes": 417939,
    "passages": 53, "sentences": 366, "tokens": 5166, "lemmas": 1200,
    "hasTranslation": false,
    "freq": { "ὁ": 412, "καί": 230, "…": 1 }
  }]
}
```

`freq` is the per-text lemma frequency (punctuation excluded). The app computes "X% of this text readable" as the share of tokens whose lemma the learner knows, without loading the text.

## lexicon.json

`{ lemma: { "s": short gloss for the interlinear line, "d": longer definition } }`, restricted to lemmas that occur in the corpus. From Logeion's short definitions; a proper name with no entry gets `(name)`.

## texts/<id>.json

```json
{
  "id": "plato-euthyphro", "title": "Euthyphro", "author": "Plato", "stage": 3,
  "dialect": "Attic", "description": "…", "scheme": "agdt", "analysis": "manual",
  "source": { "name": "…", "license": "…", "url": "…" },
  "translation": { "name": "…", "license": "…", "url": "…" },
  "optional": false,
  "passages": [{
    "id": "plato-euthyphro:2", "title": "Stephanus page 2", "ref": "2",
    "tr": { "2a": "What strange thing has happened, Socrates…", "2b": "…" },
    "s": [{
      "id": "plato-euthyphro:1", "ref": "2a", "sp": "Εὐθύφρων",
      "t": [
        { "f": "τί", "l": "τίς", "p": "p-s---nn-", "h": 6, "r": "SBJ" },
        { "f": "νεώτερον", "l": "νεώτερος", "p": "a-s---nn-", "h": 0, "r": "ATR" }
      ]
    }]
  }]
}
```

Token fields: `f` surface form (NFC), `l` normalised lemma, `p` nine-position AGDT postag, `h` index of the head token within the sentence (`-1` for the root), `r` dependency relation in the text's `scheme`, `g` a contextual gloss when the treebank has one (Aesop).

`scheme` is `agdt` (Perseus, Gorman, GLAUx) or `proiel` (John). `analysis` is `manual` or `auto`.

Translations: `tr` maps a citation ref to the translation of that section. A sentence's translation is `tr[sentence.id]` if a sentence-level one exists (generated by `translate.py`), else `tr[sentence.ref]`. Several sentences usually share one ref.

## The postag

| position | values |
|---|---|
| 1 part of speech | n noun, v verb, a adjective, d adverb, l article, g particle, c conjunction, r preposition, p pronoun, m numeral, i interjection, e exclamation, u punctuation, x other |
| 2 person | 1 2 3 |
| 3 number | s p d |
| 4 tense | p present, i imperfect, r perfect, l pluperfect, t future perfect, f future, a aorist |
| 5 mood | i indicative, s subjunctive, o optative, n infinitive, m imperative, p participle |
| 6 voice | a active, p passive, m middle, e middle/passive |
| 7 gender | m f n |
| 8 case | n g d a v l |
| 9 degree | c comparative, s superlative |

Unused positions are `-`. PROIEL morphology is mapped onto this in `pipeline/proiel.py`.
