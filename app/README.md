# app

Vite + React + TypeScript front end. See the repository README for the whole project.

```sh
npm install
npm run dev      # development server
npm run build    # static site in dist/
```

The corpus it reads is in `public/data/`, generated by `../pipeline/build.py`.

Layout: `src/greek` (morphology, dependency structure, construction detectors), `src/learner` (learner model, quiz generation), `src/content/grammar.ts` (grammar notes), `src/views` (screens), `src/llm` (optional Claude grader).
